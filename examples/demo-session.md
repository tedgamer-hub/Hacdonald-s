# 演示流程

本文件是可复现的演示脚本，不是已经通过的实时价格记录。修正后多人在线核价尚未完成，当前不提供虚构的成功金额。

场景：麦当劳沈阳盛京大奥莱餐厅，3 人，总预算 80 元。成员 1 偏好鸡肉名称，成员 2 不要饮料，成员 3 比较饿。

1. 让宿主模型使用 `skills/hacdonalds/`，将需求整理成 `examples/team-request.json` 的结构。
2. 执行 `uv run python scripts/verify_team.py`，重新查询当前门店，读取当前菜单和单品详情，搜索成员分配并官方核价。
3. 只在 status 为 verified 时展示逐人餐品、官方总价、剩余预算和核价时间。没有三种不同方案时展示实际数量。
4. 继续说：“成员 1 也不要饮料，总预算改成 75 元，其他不变。”修改后的协议见 `team-request-revised.json`。验收脚本会自动执行这一轮，并重新查询整篮价格。
5. 检查 `.local/team-check.json` 的最终状态和两轮结果。该文件包含完整本地记录，不随项目发布。

若返回连接超时，明确说明尚未获得实时核价。若用户提出“不吃牛肉”等禁忌，保留 avoid 并说明当前无法核实配料，不把该要求偷换成名称关键词过滤。
